# Khana Khazana Restaurant Website 🍽️

A beautiful, modern, and interactive website for **Khana Khazana Restaurant**, featuring a special Bengali theme celebrating **Rath Yatra (শুভ রথযাত্রা!)**.

## ✨ Features
- 🌟 **Premium design & rich aesthetics** with responsive layouts.
- 🎡 **Interactive Rath Yatra special section** featuring a floating Rath Chariot.
- 🎠 **Dynamic Hero Section** with a smooth-sliding banner background.
- 💬 **Customer Reviews & Testimonials** slider.
- 📱 **Mobile-responsive navigation** with a hamburger menu.
- 🚀 **Preloader Screen** with modern transition animations.

## 📂 Project Structure
- `index.html` - The main structure of the restaurant website.
- `styles.css` - Custom styling with premium typography (Outfit, Playfair Display, Inter) and color scheme.
- `script.js` - Javascript animations and logic for the carousel, reviews, and preloader.
- `assets/` - Folder containing banners, logos, icons, and review images.
- `git_update.bat` - Git Auto-Update script for Windows.

## ⚙️ Running Locally
Simply open the `index.html` file in any modern web browser, or use a local development server (like VS Code Live Server).

## 🚀 Git Auto-Updater Script (`git_update.bat`)
To make pushing updates to your GitHub repository easier, we've created a custom batch script for Windows.

### How to use it:
1. Make any edits to your website files.
2. Double-click the **`git_update.bat`** file in your project folder.
3. The script will:
   - Check the repository status.
   - Stage all new, deleted, or modified files (`git add .`).
   - Prompt you to enter a custom commit message (or press **Enter** to use the default message `"Website update"`).
   - Commit the changes locally.
   - Push the changes to your GitHub remote repository automatically!
